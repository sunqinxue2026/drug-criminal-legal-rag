# 涉毒刑事 RAG 评测说明

## 目标

该评测用于支撑论文中的“系统测试与结果分析”章节，重点验证以下问题：

- 回答是否能够稳定输出结构化四段内容：`初步结论 / 法律依据 / 风险提示 / 行动建议`
- 回答是否给出足够的 RAG 检索引用
- 回答与引用内容是否覆盖问题中的关键法律要点

## 评测集

评测数据位于：

- `data/evaluation/drug_rag_eval_set.json`

当前评测集覆盖 8 类高频涉毒刑事咨询场景，包括：

- 家属收到拘留通知后的第一步应对
- 取保候审的适用条件
- 侦查阶段律师会见权利
- 聊天记录与转账记录的证据作用
- 非法持有毒品罪与容留他人吸毒罪的区分
- 自首、立功、认罪认罚对处理结果的影响
- 未成年人涉依托咪酯场景的法律风险
- `12309` 检察服务热线可提供的帮助

## 运行方式

先确保以下服务已经启动：

1. `web-springboot`，默认地址 `http://localhost:8080/api`
2. `web-flask`，默认地址 `http://localhost:5000`

然后在项目根目录运行：

```powershell
python scripts/evaluate_drug_rag.py
```

可选参数示例：

```powershell
python scripts/evaluate_drug_rag.py --endpoint http://localhost:5000/api/chat --output logs/drug_rag_eval_report.json
```

## 输出指标

脚本会输出并保存以下指标：

- `pass_rate`
- `section_completeness_rate`
- `citation_presence_rate`
- `avg_keyword_hit_rate`
- 每道题的回答预览、引用数和单项通过情况

## 判定规则

单题默认通过需要同时满足：

- `structured_answer` 中要求的字段全部非空
- 返回的引用数量不少于题目要求的 `min_references`
- 回答与引用合并后的文本中，关键关键词命中率不低于 `0.5`

## 论文中可直接引用的表述

可在论文中写为：

“为验证系统在涉毒刑事法律咨询场景中的问答质量，本文构建了一个小规模专题评测集，并设计了自动化评测脚本。评测从结构化回答完整性、引用支撑情况和关键法律信息覆盖度三个维度对系统输出进行量化分析，从而为后续的知识库扩充与提示词优化提供可重复的实验依据。”

## 建议呈现方式

答辩或论文图表中建议至少展示：

- 8 个问题的总体通过率
- 结构化回答完整率
- 引用存在率
- 1 到 2 个代表性问题的回答截图与引用来源截图
